# Content OS

Sistema de estratégia e produção de conteúdo no modelo de crescimento liderado pelo fundador, para **YouTube, Instagram, LinkedIn e X** a partir de uma base única. Roda dentro de qualquer assistente de IA que consiga ler uma URL (Claude, ChatGPT, Gemini).

Você responde a entrevista uma vez. Uma peça principal (normalmente um vídeo longo) vira o pacote da semana em todas as redes, cada peça adaptada às regras da rede.

## Como usar

Cole isto numa conversa nova com o seu assistente de IA:

```
Leia https://raw.githubusercontent.com/Synaptica24/content-os/main/START.md e rode comigo.
```

Se você já tem um onboarding ou uma estratégia de outro sistema, cole junto. O assistente aproveita o que já existe e pergunta só o que falta.

Dica: num Projeto do Claude (ou equivalente), guarde os documentos que o sistema gera nos arquivos do projeto. Assim todas as conversas leem a mesma base.

## Como está organizado

```
START.md              núcleo: entrevista, estratégia central, banco de provas,
                      calendário unificado, cascata, CPIO, qualidade e escrita
modulos/youtube.md    vídeo longo, títulos, thumbnails, roteiro, Shorts, métricas
modulos/instagram.md  reels, carrosséis, stories, caminho até a DM, métricas
modulos/linkedin.md   posts, documentos, perfil B2B, métricas
modulos/x.md          posts curtos, threads, respostas, fase de largada, métricas
```

O assistente lê o núcleo e só os módulos das redes que você escolher.

## O que o sistema faz

1. **Entrevista única:** 28 perguntas do núcleo (19 essenciais) mais as perguntas de cada rede escolhida.
2. **Núcleo da marca e Banco de provas:** quem você é, para quem, e as provas que pode usar, num lugar só.
3. **Estratégia central:** promessa, funil 40/40/20, pilares, caminho até o cliente, papel de cada rede e cadência total que cabe no seu tempo.
4. **Banco de 20 ideias núcleo** com peça principal e desdobramentos, e um calendário semanal unificado.
5. **Cascata:** uma peça principal vira o pacote da semana (cortes, carrossel, post, thread), sem copiar e colar o mesmo texto.
6. **Produção e revisão** de cada peça no formato certo de cada rede.
7. **Check-in semanal, plano de gravação em viagem, temas do momento e revisão de desempenho** por rede, ligada a resultado de negócio.
